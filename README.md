# LessonLog

Трекер уроків: кнопка «+» додає урок (дата, тип, години, нотатка), є статистика по місяцях і заробіток по кожному типу уроку. Дані зберігаються в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Відкриється на `http://localhost:5173`.

## Збірка для деплою (GitHub Pages / Netlify / Vercel)

```bash
npm run build
```

Готові статичні файли з'являться в `dist/`, їх і деплоїш.

## Структура

```
src/
  composables/
    useLessons.js       — CRUD для записів уроків + збереження в localStorage
    useLessonTypes.js   — CRUD для типів уроків і цін + збереження в localStorage
  components/
    BaseButton.vue       — перевикористовувана кнопка
    BaseInput.vue         — перевикористовуване поле вводу з підписом
    BaseSelect.vue         — перевикористовуваний select з підписом
    AppTabs.vue             — перемикач вкладок
    LessonForm.vue           — форма додавання уроку (відкривається по "+")
    LessonItem.vue            — один рядок уроку в списку
    LessonList.vue             — список уроків (або порожній стан)
    StatsPanel.vue              — статистика за обраний місяць
    TypeSettings.vue             — керування типами уроків і цінами
  App.vue                         — вкладки + кнопка "+"
```

## Що можна додати далі

- Синхронізація через Supabase (щоб дані не губились при очищенні кешу і були доступні з будь-якого пристрою)
- PWA-маніфест, щоб застосунок можна було "встановити" на телефон
- Експорт статистики в CSV
- Графік динаміки годин/заробітку по місяцях
